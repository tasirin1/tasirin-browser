# Tasirin Browser

Browser Android ringan berbasis **WebView** dengan halaman bookmark sebagai tampilan utama dan mode cursor untuk navigasi tanpa sentuhan layar.

## Fitur utama

- **Halaman bookmark** — tampilan utama menampilkan daftar bookmark; tap untuk buka.
- **Mode cursor** — toggle ke mode cursor untuk menggerakkan pointer pakai tombol panah (D-pad) atau tombol on-screen; tap tengah untuk klik di posisi pointer.
- **Address bar** — input URL / pencarian; back & forward navigation.
- **Bookmark management** — tambah / hapus bookmark dari menu atau tombol ★.
- **WebView ringan** — JavaScript aktif, DOM storage, zoom kontrol.

## Download

Download APK terbaru dari [GitHub Releases](https://github.com/tasirin1/tasirin-browser/releases/latest).

```bash
./gradlew assembleDebug
```
