# Tasirin Browser

Lightweight Android **WebView** browser with bookmarks as the home page and cursor mode for touch-free navigation.

## Features

- **Bookmarks page** — main view shows bookmark list; tap to open.
- **Cursor mode** — toggle to move a pointer with arrow keys (D-pad) or on-screen buttons; center tap to click.
- **Address bar** — enter URL / search; back & forward navigation.
- **Bookmark management** — add / remove bookmarks from menu or ★ button.
- **Lightweight WebView** — JavaScript enabled, DOM storage, zoom controls.

## Download

Get the latest APK from [GitHub Releases](https://github.com/tasirin1/tasirin-browser/releases/latest).

## Build

```bash
./gradlew assembleDebug
```
